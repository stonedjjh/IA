# Curso 6: Creación de aplicaciones generativas basadas en IA con Python

## Acerca de este Curso
¿Listo para una experiencia de aprendizaje interactiva para crear aplicaciones de IA generativa y chatbots del mundo real? En este curso práctico, desarrollarás una serie de proyectos guiados utilizando Python, Flask, Gradio y LangChain para crear aplicaciones impulsadas por IA para escenarios prácticos, incluyendo un asistente de voz, un resumidor de reuniones, un traductor de idiomas y un entrenador profesional personalizado. Trabajará con modelos de lenguaje grandes y populares (LLM) como GPT-3, Llama 2 y Flan-UL2, alojados en plataformas como IBM watsonx y Hugging Face. También explorará conceptos avanzados, como la generación aumentada de recuperación (RAG), para mejorar las respuestas LLM con conocimiento externo, e integrará voz a texto (STT) y texto a voz (TTS) utilizando IBM Watson® Speech Libraries y OpenAI Whisper para permitir interacciones de voz. Aunque un conocimiento básico de Python es esencial, el conocimiento de HTML, CSS o JavaScript es útil pero no obligatorio. El curso incluye lecturas y vídeos de apoyo para adquirir conocimientos básicos sobre los modelos y marcos utilizados. Además, un completo glosario del curso le ayudará a reforzar su aprendizaje.
